# Australian Comparison Platform

A modern web application for comparing various Australian services including electricity, gas, internet, insurance, and home loans.

## Features

- Compare electricity plans
- Compare gas plans
- Compare internet plans
- Compare insurance options
- Compare home loans
- Secure authentication
- Real-time price updates
- User-friendly interface

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Vercel Deployment
- JWT Authentication
- API Integration

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/australian-comparison-platform.git
```

2. Install dependencies:
```bash
cd australian-comparison-platform
npm install
```

3. Set up environment variables:
Create a `.env.local` file with the following variables:
```
NEXT_PUBLIC_SITE_URL=http://localhost:3000
JWT_SECRET=your_jwt_secret
SESSION_SECRET=your_session_secret
```

4. Run the development server:
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
